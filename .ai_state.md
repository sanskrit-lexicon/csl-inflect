- Correction facility (#11): `decline_one.py` shows a correction alongside the algorithmic
  declension when the algorithm and a hand-verified correction disagree (see
  `stems_problem.txt` / `lexnorm-all2.txt` for the nominals this applies to).
- Mobile layout: the lookup UI uses three absolute-positioned panes; without the viewport
  meta tag, mobile browsers rendered at a virtual ~980px viewport, pushing `#disp`
  (`left:35%`) off-screen on a 375px phone. Fixed via viewport meta + a `max-width:700px`
  breakpoint that stacks the panes — desktop layout (>700px) is untouched by this fix.
